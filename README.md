💰 Expense Tracker Web Application
Project Overview

A full-stack Expense Tracker website that helps users record, track, and analyze their daily income and expenses. The application provides a clean, intuitive interface to add transactions, view balances, and analyze spending patterns over time, with persistent data storage using a backend server.

Key Features

➕ Add Transactions – Easily add income and expense entries with amount and description

📊 Real-time Balance Calculation – Automatically updates total balance, income, and expenses

📜 Transaction History – Displays a detailed list of all transactions

📅 Daily Log Book View – View transactions grouped by date with daily totals

🧮 Income vs Expense Breakdown – Clear separation and visualization of income and expenses

🔄 State Management using Context API – Centralized and efficient state handling

🌐 Backend Integration – Data persistence using a Node.js + Express backend

📱 Responsive UI – Works smoothly across different screen sizes

Tech Stack

Frontend

React.js

JavaScript (ES6+)

CSS

Context API for global state management

Backend

Node.js

Express.js

RESTful APIs

Database

MongoDB (for persistent transaction storage)

Project Structure Highlights

components/ – Modular React components such as Balance, TransactionList, LogBook, and DetailedHistory

context/ – Global state management using React Context

backend/ – Express server handling API routes and database operations

assets/ – Static assets and images

Clean separation of frontend and backend for scalability
